# Telegram-бот «Учёт смен»

## Запуск
1. Установите Python 3.10+.
2. Создайте бота через @BotFather и получите токен.
3. Узнайте свой Telegram ID (например, через @userinfobot).
4. Установите зависимости: `pip install -r requirements.txt`.
5. Задайте переменные окружения `BOT_TOKEN`, `OWNER_ID`, `BOT_TIMEZONE` (например, `Europe/Moscow`).
6. Запустите `python bot.py` на постоянно работающем компьютере или сервере.

Linux/macOS:
```
export BOT_TOKEN='ВАШ_ТОКЕН'
export OWNER_ID='123456789'
export BOT_TIMEZONE='Europe/Moscow'
python bot.py
```

Windows PowerShell:
```
$env:BOT_TOKEN='ВАШ_ТОКЕН'
$env:OWNER_ID='123456789'
$env:BOT_TIMEZONE='Europe/Moscow'
python bot.py
```

## Использование
- Отправьте `Кириллов к 7:00` или несколько строк — бот создаст смены на сегодня.
- `/today` — список на сегодня, `/list 2026-11-08` — история конкретного дня.
- Галочка «Ответил» — независимый статус подтверждения.
- «Завершить» — ввод окончания в формате `12:00`; при переходе через полночь время автоматически относится к следующему дню. Для явной даты используйте `2026-11-09 01:00`.
- «Изменить время» — изменение начала, «Изменить окончание» — исправление завершения.
- `/report` и `/report 2026-11` — месячные итоги.
- `/addadmin TELEGRAM_ID` — дать второму человеку доступ; `/removeadmin TELEGRAM_ID` — отозвать. Только владелец может это делать.

Все администраторы видят общую базу, но кнопки в ранее отправленных сообщениях Telegram могут не обновиться автоматически в другом чате. При нажатии они обращаются к актуальной базе; `/today` всегда показывает актуальный статус. Бот не проверяет реальные приходы сотрудников и считает время от введённого начала. Перерывы не вычитаются. SQLite-файл `shifts.sqlite3` нужно регулярно резервировать.

## Bothost.ru
Загрузите ZIP-архив в проект Telegram/Python. Главный файл: `bot.py`.
В переменных окружения укажите `OWNER_ID` (ваш Telegram ID), `BOT_TIMEZONE` (например, `Europe/Moscow`), `BOT_DB=/app/data/shifts.sqlite3`. `BOT_TOKEN` Bothost предоставляет при создании бота; не публикуйте токен.
Убедитесь, что на тарифе включено постоянное хранилище `/app/data`.
